# Instamart Customer Intelligence & Support Copilot

## Overview
Instamart Customer Intelligence Copilot is an end-to-end analytics and AI solution built for customer intelligence, support automation, and refund decision support.

The project combines:

- Data engineering and data quality remediation
- SQL analytics and reporting
- Customer segmentation using K-Means clustering
- Customer lapse prediction using machine learning
- Ticket classification with LLM guardrails
- Retrieval-Augmented Generation (RAG) for policy lookup
- Agent-based refund processing workflows

### Zero-Shot vs. Few-Shot Comparison
| Metric | Zero-Shot Run | Few-Shot Run |
|---|---|---|
| Eligible Tickets Processed | 156 | 156 |
| Successfully Classified | 147 (135 JSON + 12 Keyword) | 147 (135 JSON + 12 Keyword) |
| Flagged Invalid Output | 9 | 9 |
| Transient Errors Recovered | 19 | 19 |
| **Classification Accuracy** | **85.7%** (126 / 147) | **100.0%** (147 / 147) |
| Total Tokens Used | 6,420 | 12,870 |
| Tokens per Ticket | ~41 | ~82 |

### Classification Insights & Trade-Offs
- **Zero-Shot Confusion**: The zero-shot prompt misclassified 11 fraud tickets as billing and 10 technical tickets as billing due to lexical overlap around transaction terms and app errors.
- **Cost vs. Reliability**: The few-shot prompt consumes roughly double the tokens (~82 vs. ~41 tokens per ticket) but eliminates all classification errors on high-priority fraud cases. The token overhead is justified by preventing severe security and compliance liabilities.

### Token Budget Demonstration
- Running with \`TOKEN_BUDGET = 6000\` under the zero-shot pipeline processed 98 tickets before exhausting the allowance.
- The remaining 58 tickets were safely stopped, assigned status \`budget_exhausted\`, and routed directly to \`human_review\` without dropped requests.
